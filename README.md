# NextMove

NextMove è una Progressive Web App mobile-first che suggerisce il prossimo task in base a importanza, urgenza, scadenza, durata, tempo disponibile ed energia mentale.

## Privacy

I task e le impostazioni restano nel `localStorage` del dispositivo. Nessun task personale viene inviato al repository o a un server.

## Installazione Android

Apri il sito GitHub Pages con Chrome e scegli **Installa app** oppure **Aggiungi alla schermata Home**.
